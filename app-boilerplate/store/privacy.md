# Privacy policy

Replace this page before store submit. Host it on GitHub Pages and put the HTTPS URL in `lib/config/app_config.dart`.

**App name:** App Boilerplate  
**Contact:** support@nojic.net · privacy@nojic.net

## Data we collect

- Purchase status from Apple App Store or Google Play (via RevenueCat if configured).
- Photos or camera frames you choose to analyze, sent to the identification API if the weekly app uses one (Gemini or similar). Images are not stored on our servers by default.
- Crash-free diagnostics provided by the store.

We do not create user accounts unless a later version says otherwise.

## Third parties

- Apple and Google for in-app purchases.
- RevenueCat if API keys are set.
- Google Gemini or another model provider if the app identifies images or text.

## Your choices

- Restore purchases from Settings.
- Request deletion of any account data by emailing support. This boilerplate does not create accounts.

## Changes

We will update this page if data practices change.
